## 📖 项目简介

这是一款基于 Python 开发的**命令行随机抽取工具**，适用于课堂点名、抽奖活动、随机分组等场景。  
程序支持**多名单管理**、**抽取记录追踪**、**学生预约抽取**、**密码保护**以及**数据加密存储**，确保数据安全与操作便捷。

---

## ✨ 主要功能

- ✅ **多学生名单管理**：支持创建、修改、删除、导出多个独立名单。
- 🔐 **Fernet 对称加密**：所有名单及记录数据均加密存储，保障隐私。
- 🔑 **密码保护**：修改名单、清空记录等敏感操作需密码验证。
- 📋 **抽取记录追踪**：自动记录已抽取学生，避免重复抽取。
- 📌 **预约抽取**：可提前将特定学生加入下一轮抽取队列。
- 📂 **数据持久化**：程序数据统一保存在用户目录下的 `Python_Random_Select` 文件夹中。
- 🖥️ **纯键盘交互**：全程通过键盘按键操作，简洁高效。

## 🛠️ 安装与运行

### 环境要求
- Python 3.6 及以上
- 依赖库：`cryptography`

### 安装步骤

1. 克隆或下载本程序源码。
2. 安装依赖：
   ```bash
   pip install cryptography
   ```
3. 运行程序：
   ```bash
   python 随机抽取.py
   ```

> 💡 程序首次运行时会自动生成加密密钥、创建数据目录，并引导您创建第一个学生名单。

## 🧭 使用指南

### 1. 初次启动
- 程序会自动检测是否存在学生名单。
- 若无，则会在桌面生成 `请在这里输入学生名单.txt`，按格式填写后，程序读取并加密保存。

### 2. 主交互界面
启动后，您可以选择已存在的学生名单，之后进入抽取主循环：

```
请输入需要抽取的学生个数或命令：
```

### 3. 支持的命令

| 命令关键词（不区分大小写） | 功能说明 |
|---------------------------|----------|
| `数字`（如 `5`）          | 随机抽取指定数量的学生 |
| `清空记录` / `qk` / `clean` | 清空当前名单的抽取记录（需密码） |
| `记录` / `jl` / `recorded` | 查看已抽取的学生列表 |
| `添加记录` / `tj`         | 手动将某学生加入抽取记录（需密码） |
| `预约` / `yy`             | 将指定学生加入预约抽取队列（需密码） |
| `修改密码` / `xgmm`       | 修改程序密码（需旧密码验证） |
| `修改学生名单` / `xg`     | 进入名单管理子菜单（增删改查） |

## 🗂️ 数据存储说明

程序数据默认保存在：
```
C:\Users\你的用户名\AppData\Roaming\Python_Random_Select\
```

包含以下文件：
- `list_*.dll`：加密的学生名单文件
- `Fernet_key.dll`：加密密钥（请勿删除或修改）
- `password.dll`：加密的密码
- `recorded_students_*.dll`：对应名单的抽取记录
- `add_students.dll`：预约学生列表
- `recorded_add_students.dll`：已抽取的预约学生记录

> ⚠️ 请勿手动删除或修改 `Fernet_key.dll`，否则将导致数据无法解密。

---

## 🧪 异常处理

- 程序会自动捕获异常并记录到桌面上的 `随机抽取_错误日志.log`。
- 若密钥文件丢失，程序会提示恢复或清除已有名单。

---

## 📌 注意事项

- 本程序目前**仅支持 Windows 系统**（因使用了 `msvcrt` 模块）。
- 输入学生名单时，请确保第一行为名单名称，后续每行为一个学生姓名。
- 预约抽取的学生若已被抽取，则自动从预约列表中移除。
